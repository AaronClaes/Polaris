# Polaris

One home for all your dev projects. Polaris is a macOS command center that
brings your quicklinks, one-click commands, and live GitHub issues and PRs
together in one place.

## Requirements

- Node 22+
- pnpm 11+
- macOS

## Run

```sh
pnpm install
pnpm dev
```

## Build

```sh
# Bundle the app
pnpm build

# Package a macOS .app / .dmg into dist/
pnpm build:mac
```
